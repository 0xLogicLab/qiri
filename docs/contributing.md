# 参与 QIRI

请在 [QIRI issue tracker](https://github.com/0xLogicLab/qiri/issues)提交问题、研究场景需求或可复现的分析。提交前先搜索已有 issue。

问题报告应包含 QIRI 版本、操作系统、配置方式、最小复现步骤、预期和实际结果，以及脱敏后的日志。科研问题请说明数据来源与可公开的最小样例。不要上传 API Key 或敏感数据。

代码变更应聚焦单一问题，说明动机和验证结果。保留上游许可证、NOTICE 和版权头；内部 crate、协议与环境变量的更名需要单独评估兼容性。构建与测试说明见[安装](install.md)。

尊重不同背景的参与者，基于事实讨论问题。安全漏洞按[安全策略](../SECURITY.md)处理，不要在公开 issue 中披露利用细节。
